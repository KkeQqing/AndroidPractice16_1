 确保同一 Wi-Fi 并获取 IP 地址
将 设备 A 和 设备 B 连接到 同一个路由器（同一个 Wi-Fi）。

查看每台设备的局域网 IP：

通常路径：设置 → WLAN → 点击当前连接的 Wi-Fi → 在详情中看到「IP 地址」，例如：

设备 A：192.168.1.101

设备 B：192.168.1.102

重要：如果 IP 是 10.x.x.x 或 172.x.x.x，也属于局域网，正常使用。

2️⃣ 输入配置（设备 A）
在设备 A 上打开应用，界面如下（字段说明）：

text
[ 对方 IP         ]  [ 对方端口  ]   [ 本地端口  ]
[  192.168.1.102  ]  [  5678     ]   [  1234    ]
对方 IP：填入设备 B 的 IP → 192.168.1.102

对方端口：设备 B 的监听端口 → 5678（这是 B 用来接收数据的端口）

本地端口：设备 A 自己的监听端口 → 1234（A 用来接收 B 数据的端口）

点击 「连接」（或「开始」）。

3️⃣ 输入配置（设备 B）
在设备 B 上打开应用：

text
[ 对方 IP         ]  [ 对方端口  ]   [ 本地端口  ]
[  192.168.1.101  ]  [  1234     ]   [  5678    ]
对方 IP：填入设备 A 的 IP → 192.168.1.101

对方端口：设备 A 的监听端口 → 1234

本地端口：设备 B 自己的监听端口 → 5678

点击 「连接」（或「开始」）。
